# SMILE Tech Stack Update - Release Notes

**Release Date:** March 31, 2026  
**Status:** Production Ready

---

## Summary

This release eliminates proprietary dependencies from SMILE by replacing them with open-source alternatives and implementing provider-agnostic architectures in both Backend and Frontend.

---

## Backend Changes

### 1. Mail Provider - AWS SES to Pluggable Provider
Replaced hardcoded AWS SES dependency with a flexible Mail Provider abstraction supporting SES, SMTP, and future providers.

**Commit:** `a82f7ca49cb22669e8228e0976d68e4a8d31f3fd`

**Files Changed:**
- `apps/notification/src/lib/mail/index.js` (NEW) - Factory pattern implementation
- `apps/notification/src/lib/mail/types.js` (NEW) - MailProvider interface
- `apps/notification/src/lib/mail/ses-provider.js` (NEW) - AWS SES implementation
- `apps/notification/src/lib/mail/smtp-provider.js` (NEW) - SMTP implementation
- `apps/notification/src/email.worker.js` (MODIFIED) - Refactored to use MailProvider
- `apps/notification/.env.example` (MODIFIED) - Added MAIL_PROVIDER configuration

## Environment Variables

### Backend (.env)
```bash
# Mail Provider
MAIL_PROVIDER=ses  # Options: ses, smtp
SMTP_HOST=your_smtp_host
SMTP_PORT=587
SMTP_USER=your_smtp_user
SMTP_PASSWORD=your_smtp_password
MAIL_SENDER=noreply@example.com

# AWS (if using SES)
AWS_ACCESS_KEY_ID=your_key
AWS_SECRET_ACCESS_KEY=your_secret

# Firebase (if using FCM)
FIREBASE_PROJECT_ID=your_project_id
FIREBASE_PRIVATE_KEY=your_private_key
FIREBASE_CLIENT_EMAIL=your_client_email

# Message Queue
AMQP_SERVER=amqp://localhost:5672
```

### Frontend (.env)
```bash
# Firebase Configuration (now via env vars)
NEXT_PUBLIC_FIREBASE_API_KEY=your_api_key
NEXT_PUBLIC_FIREBASE_AUTH_DOMAIN=your_project.firebaseapp.com
NEXT_PUBLIC_FIREBASE_PROJECT_ID=your_project_id
NEXT_PUBLIC_FIREBASE_STORAGE_BUCKET=your_project.appspot.com
NEXT_PUBLIC_FIREBASE_MESSAGING_SENDER_ID=your_sender_id
NEXT_PUBLIC_FIREBASE_APP_ID=your_app_id
NEXT_PUBLIC_FIREBASE_VAPID_KEY=your_vapid_key
```
