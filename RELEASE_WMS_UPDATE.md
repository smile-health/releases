### Feature Updates in this release
----
- Update “Remember Me” to store only the username <sup>_Enhancement_</sup>
- Update time filter format to 00:00 – 23:59 <sup>_Enhancement_</sup>
- Update filter to use UTC <sup>_Enhancement_</sup>
- Add multiple partnership in follow up treatment menu <sup>_Enhancement_</sup>

----

#### Update “Remember Me” to store only the username
This update improves security and user experience by ensuring that the “Remember Me” feature stores only the username instead of full login credentials. 
By limiting the stored data to non-sensitive information, the system reduces security risks while still allowing users to quickly recognize and reuse 
their account during login.
![Image](images/wms/1.1.png)

#### Update time filter format to 00:00 – 23:59
The time filter has been updated to use a standardized 24-hour format (00:00 – 23:59). This ensures consistency across the system and eliminates 
ambiguity between AM and PM formats. It also improves clarity for users when selecting and interpreting time ranges for filtering data.

![Image](images/wms/1.2.png)

#### Update filter to use UTC
The filtering system has been updated to use Coordinated Universal Time (UTC) as the standard time reference. This change ensures consistency across 
different time zones, prevents discrepancies in time-based data, and improves accuracy in reporting and data synchronization across systems.

#### Add multiple partnership in follow up treatment menu
The “Add Multiple Partnership” feature in the follow-up treatment menu allows users to associate multiple partners within a single follow-up process. 
In addition, the Transporter Name field now supports multiple entries, enabling users to input and manage more than one transporter within the same form.

This enhancement improves efficiency by reducing repetitive input, streamlines the workflow, and ensures better data organization when handling follow-up
treatments involving multiple partners and transporters.
![Image](images/wms/1.3.png)

#### Remember me when logging in
The “Remember Me” feature is designed to enhance user convenience during the login process by securely storing the user’s username and password 
on the device. When this option is enabled, the system automatically recalls and pre-fills the username field on subsequent visits, allowing 
users to log in more quickly without having to re-enter their credentials each time. This feature improves the overall user experience by 
reducing repetitive input while maintaining security, as sensitive information such as passwords is not stored.

![Image](images/wms/5.1.png)

#### Automatically format vehicle license plate input in the waste handover menu
The automatic vehicle license plate formatting feature in the waste handover module is designed to improve data consistency and user convenience. 
When a user enters a vehicle license plate number into the input field, the system automatically formats the input according to the standard 
plate structure. For example, if a user types “P1298KB”, the system will instantly convert it into “P 1298 KB”. This feature helps reduce manual 
formatting errors, ensures uniform data entry, and makes the information easier to read and process.

![Image](images/wms/5.2.png)

#### Waste handover group filter
The waste handover group filter feature has been enhanced by updating the Start Date and End Date fields to include a time picker. This improvement 
allows users to filter data not only by date but also by specific time ranges. With this enhancement, users can perform more precise and accurate 
searches, making it easier to track and analyze waste handover records within a defined time period. This ensures better data filtering, especially 
for scenarios that require time-specific reporting.

![Image](images/wms/5.3.png)

### Summary of the Feature Updates in this release
----
Initial public release of the WMS  Waste Management System. This release establishes the complete foundation for digitized healthcare waste tracking, 
from waste generation at the source through classification, weighing, handover, and final disposal. It includes three platform targets: the WMS web 
application for operational waste management, the Executive web application for analytics and oversight, and the mobile application for field operations.
